# 回测 / 回放 / 模拟实盘 —— 口径对照表

> 同一份模型 + 同一份数据，在三个界面里数字可能不一样 —— 这**不是 bug**，而是三种口径本来就不一样。本页把差异一次说清。

| | **策略回测**（回测页） | **历史回放**（模拟实盘页 · 历史回放面板） | **模拟实盘**（模拟实盘页 · 实时监视） |
|---|---|---|---|
| **用途** | 快速验证模型 × 持仓方案组合在历史数据上的表现（可自由换数据文件/窗口/成本/上限/阈值） | 用**同一个离散引擎**在本地 Parquet 上批量重放，验证“模拟盘口径”下方案的历史绩效；支持「同参数回测对比」双口径叠加 | 把同一引擎接到**实时行情流**上模拟成交，观察信号 → 开平仓 → 账户曲线的完整闭环，支持持仓管理/DD 熔断/飞书告警 |
| **引擎** | 双引擎分流：方案 =「信号跟随」→ 训练连续口径（`BacktestEngine`，逐 bar 连续计仓）；方案 ≠ 信号跟随 → 离散撮合引擎（`run_replay`，同模拟盘口径） | 离散撮合引擎（`run_replay`）——与模拟实盘**逐笔同构**，只是批量喂历史 bar | 离散撮合引擎（`run_replay` 同款逻辑）——按实时 tick/bar 逐根驱动 |
| **计仓（每笔投入）** | 连续口径：`仓位 = |tanh(因子)| × 上限%`（上限% = 每笔投入上限框）；离散口径：每笔 `名义 = min(满仓, 当时权益 × 上限%) × 强度` | 每笔 `名义 = min(满仓, 当时权益 × 上限%) × 强度`，同模拟盘 | 同左：`名义 = min(满仓名义金额, 当时权益 × 上限%) × 强度`；再受「满仓名义金额」货币额封顶 |
| **信号阈值** | `abs(tanh(因子)) < 阈值 → FLAT 观望`（与训练一致），阈值可配 0.05/0.3/0.5/0.8 | 同一阈值参数（共用 settings.signal_threshold） | 同一阈值参数 |
| **持仓方案** | 主方案 + 正交叠加（dd+chandelier 等自由组合）；「三轴联合回测」面板一次扫 22 个正交组合 × 上限%档 × 阈值档（合并了原 矩阵/A·B/阈值敏感性 三个面板） | 方案选择 + 同参对比回测口径 | 方案 + 正交叠加（模拟盘监控项级） |
| **成本** | 手续费/滑点（单边 %）可配，默认 0.02%/0.01%；离散口径含出场费 | 手续费/滑点同回测输入 | 手续费/滑点取 settings（与回测默认一致） |
| **年化/统计口径** | 连续口径按真实时间戳估计每年 bar 数（ppy）；离散口径按给定 periods_per_year | `periods_per_year = 105195`（M5 全时段）估算年化夏普 | 同上（M5 参考年化） |
| **数据** | 本地 Parquet（训练/切片/下载目录可选），支持样本外尾部窗口 | 本地 Parquet 手动选（浏览任意位置） | 实时数据源（Binance 等，离线时自动退化）+ 可选本地策略 |
| **输出** | 绩效卡 + 明细表 + 资金曲线 + 回测/回放双曲线叠加 + 三轴联合（全网格排名/每档最优/切片矩阵）+ 成本面板 | 资金曲线 + 绩效卡 + 「同参数回测对比」双线叠加（信号跟随 → 连续 vs 离散差异；带出场模块 → 两线重合=引擎一致性校验） | 实时账户卡片 + 持仓明细 + DD 事件日志 + 飞书告警 |
| **典型问题** | “为什么和模拟盘不一样？” —— 因为 signal 时用的是**训练连续口径**（虚拟连续仓位），模拟盘永远走**离散撮合**（bar 收盘翻仓 + 逐笔成本）；两者在信号上同源，在撮合/计仓上不同 | “为什么回放和回测不一样？” —— 同上；想对齐就选非 signal 方案或点「同参数回测对比」看两线重合度 | “为什么实盘曲线和回测曲线不同？” —— 实时数据流、时点成交价与历史回放不可能逐笔一致，看趋势与长期口径而非逐笔对齐 |

---

## 核心结论

1. **离散撮合 = 模拟实盘 = 历史回放**：三处共用 `run_replay` 的逐 bar 撮合逻辑（收盘信号翻仓、止损/止盈/移动止损、DD 熔断、每笔上限），是“可实盘”口径。
2. **连续口径只存在于 训练 + 回测页 signal 方案**：训练挖因子、评估时用连续计仓；回测页默认「信号跟随」就是为了复现训练口径，方便对齐训练分数。选非 signal 方案即切到离散口径。
3. **想对比两种口径**：回测页 / 回放页的「同参数回测对比」按钮，用完全相同的 数据/模型/方案/窗口/成本 把连续与离散两条曲线叠在一张图。
4. **三轴联合回测**（回测页「🎛 三轴联合回测 · 持仓方案 × 上限% × 无信号阈值」面板，合并了原 持仓正交组合矩阵 / 阈值敏感性·观望带 / ⚖ A/B·持仓方案对比 三个面板）：22 个正交组合 × 上限%档（如 `10,25,100`）× 阈值档（如 `0.05,0.3,0.5,0.8`）一次跑完全网格，每行 = 组合×上限×阈值；矩阵视图按「上限 × 阈值」切片查看，另给 全局最优 + 每档阈值最优 + 每档上限最优 一行决策。上限本质是“缩仓”，通常降回撤也降收益，夏普峰值一般在中间档；阈值本质是“观望带”，调高阈值减少交易、提高单笔质量。
