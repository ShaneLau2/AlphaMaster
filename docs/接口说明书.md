# AlphaMaster 接口说明书

本地量化训练/回测/实盘一体化桌面应用。服务常驻于 `http://127.0.0.1:8765`
（launchd 任务 `alphamaster-web`，代码入口 `run_web.py`）。全部 HTTP 接口返回
JSON；错误为 `{"detail": "..."}` + 4xx/5xx。FastAPI 自动文档：
`GET /docs`（Swagger UI）、`GET /openapi.json`。

接口按模块分五组：**面板/设置、数据文件与下载、训练、回测、实盘(实时)与消息推送**，
另有 CLI 与 Python 库级入口。

> **机器可读的完整清单**：`docs/api_http_generated.md`（方法/路径/请求体字段/查询参数
> 自动生成，永远与代码同步）。路由或请求模型变更后重跑：
> `python scripts/gen_api_docs.py`。本节是人工整理的要点，与生成版互补。

## 一、HTTP 接口

### 1. 服务与面板

| 方法与路径 | 说明 |
|---|---|
| `GET /api/health` | 健康检查 `{"status":"ok","version":"1.1.0"}` |
| `GET /api/routes` | 列出全部路由 |
| `GET /` | Web 前端页面（`web/static/`，js/css 带版本号缓存） |
| `GET /api/overview` | 聚合面板：当前数据文件信息（`data_file` 内含 `symbol/timeframe/bars/years_h1/valid/download_source/downloaded_at/download_count/first_downloaded_at` 等）、数据源、训练/回测状态摘要 |
| `GET /api/settings` / `PUT /api/settings` | 读/写设置。PUT body 字段均可选：`last_data_file, last_strategy_file, debug_mode, ai_provider, ai_api_key, ai_base_url, ai_model, bt_commission_pct, bt_slippage_pct` |
| `GET /api/config` | 训练参数（model_core ModelConfig 视图） |
| `GET /api/debug/logs` | 服务端日志片段；`POST /api/debug/client-log` 上报前端错误 `{level,message,context?}` |

### 2. 数据文件选择与校验

文件选择走**会话轮询**（前端不阻塞、无原生对话框依赖）：

| 方法与路径 | 说明 |
|---|---|
| `POST/GET /api/data-file/browse` | 发起文件选择会话 → `{dialog, session}` |
| `POST/GET /api/data-file/browse-poll?session=xxx[&path=...]` | 轮询结果：完成返回文件检查信息（含 `raw_bars, bars_unique, duplicate_ts, missing_columns, start_date/end_date, checks_ok`、数据源标记）；取消返回 `{cancelled:true}`；无效会话 → 400 |
| `POST/GET /api/strategy-file/browse` · `.../browse-poll` | 同上，用于 `best_*.json` 策略文件；返回含 `symbol/timeframe/formula_decoded/目录/data_source` 等 |

校验摘要（去重根数、缺列、重复时间戳、时间跨度）会在卡片上醒目展示，异常时红字提示。

### 3. 数据下载（K 线 → parquet）

| 方法与路径 | 说明 |
|---|---|
| `POST /api/data/download` | 启动下载任务。JSON：`{source, symbol, timeframe, n_bars?, mode}`<br>`source`: `binance/okx/tradingview/tongdaxin`<br>`mode`: `merge`(默认，增量归档) / `backfill`(回溯到数据源起点，仅 binance/okx) / `replace`(整档覆盖)<br>`timeframe` 用小写如 `1m/1h/4h`。单任务串行：已有任务时 409。响应 `{ok, job_id, status}` |
| `GET /api/data/download-status?job_id=` | 单任务进度；完成时含 `result`（`added_bars/fetched_bars/pages/archive_unreadable/no_change/n_bars` 等） |
| `GET /api/data/download-queue` | 队列总览：运行/排队在前，最近完成在后 |
| `GET /api/data/download-history?limit=&source=` | 下载历史面板数据：sidecar 驱动的 `(source, symbol, timeframe, bars, start, end, download_count, first_downloaded_at)` 行 + 按源统计（`per_source`） |

要点：重复下载是**增量归档**——binance/okx 会锚定档案最早 bar 往前补（`backfill` 一直补到数据源起点），无新增时文件与 sidecar 均不动、返回「已是最新」；每次真实落盘累计 `download_count`（在 `{file}.parquet.meta.json` sidecar，另存 bars/起止日期，历史面板零 IO 读取）。`replace` 才是整档覆盖。

### 4. 训练

| 方法与路径 | 说明 |
|---|---|
| `POST /api/training/start` | JSON `{data_file, from_scratch}`；数据文件校验通过后启动后台训练（每文件单实例，进行中再启 → 409）。响应含 job 信息 |
| `GET /api/training/status` | 训练状态 + 最近日志。job 行含 `symbol/current_step/train_steps/progress_pct/best_score/val_score/formula_decoded/status/history/has_checkpoint/has_strategy/holdout_bars/holdout/session_seconds/history_total_seconds` |
| `POST /api/training/stop` | 停止训练并 `sync-best`（保留/恢复冠军策略文件） |
| `POST /api/training/inspect-now` | 内置训练巡检（无 API Key）：立即对当前/最近训练日志做规则诊断（停滞/分布塌缩/与冠军对比/是否值得继续），返回 `{ok, entry}` |
| `GET /api/training/{symbol}/export` | 打包导出 zip（历史/检查点/报告） |
| `POST /api/training/import` | 导入训练包（multipart） |
| `GET /api/strategies` | 策略列表（web 表：列含 品种/周期/best_score/训练数据(data_source) 等） |
| `GET /api/strategies/{symbol}/export` | 导出策略 JSON |
| `GET /api/symbols/{symbol}` | 单品种信息 |
| `POST/GET /api/strategy-file/sync-best?symbol=` | 把训练产物同步为 `strategies/best_{symbol}.json`（找不到时 404） |

冠军闸门说明：训练只以 walk-forward val 提名 top-K（`_finalists`），最终冠军在**从未参与训练/选优的尾部 holdout 窗口**按生产口径（`FINALIST_COST_RATE=0.0003`、tanh 仓位）回测选出；holdout 闸门不过（分≤0 / 保持率<0.30 / Sharpe<0 / 同数据版本已被消费）时**不覆盖** `strategies/best_{symbol}.json`，恢复旧冠军并把事件追加到 `strategies/champion_history.json`。冠军被拒时自动跑 **P3 稳健性复核**（成本/折叠/起点三轴敏感性，见 `model_core/robustness.py`），`verdict: robust|brittle` 随拒绝记录写入 champion_history。

### 5. 回测

| 方法与路径 | 说明 |
|---|---|
| `POST /api/backtest/start` | JSON `{strategy_file, commission_pct?, slippage_pct?}`（默认佣金+滑点合成 0.0003） |
| `GET /api/backtest/status` | 回测状态 |
| `POST /api/backtest/stop` | 停止 |
| `GET /api/backtest/report` | 多因子报告（Sharpe/Sortino/收益/MDD/交易数等） |
| `GET /api/backtest/equity` | 资金曲线原始数据（前端渲染图表） |
| `GET /api/backtest/chart/{name}` | 图表 HTML |

### 6. 实盘 / 实时数据与消息推送

| 方法与路径 | 说明 |
|---|---|
| `GET /api/realtime/sources` | 数据源列表与状态 |
| `POST /api/realtime/tradingview/probe` | 探测 TradingView 连通性 |
| `GET /api/realtime/strategies` | 已保存 `best_*.json` 策略（因子来源下拉） |
| `GET /api/realtime/status` | 盯盘状态 |
| `POST /api/realtime/watch` | JSON `{source, symbol, timeframe, strategy_file}` 加盯 |
| `POST /api/realtime/unwatch` | JSON `{id}` |
| `POST /api/realtime/start` / `stop` | 启动/停止实时循环 |
| `GET/PUT /api/realtime/feishu` | 飞书推送配置（`enabled/webhook_url/secret`） |
| `POST /api/realtime/feishu/test` | 飞书推送测试 |

### 7. AI 分析

| 方法与路径 | 说明 |
|---|---|
| `GET /api/ai/providers` | 可用 AI 提供方/模型 |
| `POST /api/ai/analyze-training` | 训练结果分析（流式）：`{provider?, api_key?, base_url?, model?, symbol?}` |

## 二、CLI（命令行）

```bash
# Web 服务（launchd 亦可直接拉起）
python run_web.py --host 127.0.0.1 --port 8765

# 单文件训练（冠军闸门/部署纪律内置）
python train_file.py --data-file data/training/BTCUSDT_H1.parquet
python train_file.py --data-file X.parquet --seed 42            # 单 seed
python train_file.py --data-file X.parquet --seeds 17,23,31     # 多 seed 升级纪律
python train_file.py --data-file X.parquet --steps 20 --no-deploy   # 短跑/仅评估不部署

# 生产口径回测（策略 JSON 内含 data_file 时可省略）
python run_backtest.py --strategy-file strategies/best_BTCUSDT.json \
                       --data-file data/training/BTCUSDT_H1.parquet \
                       --commission 0.02 --slippage 0.01

# 下载（批量）
python download_okx_klines.py --out <dir> [--max-bars N] [--resume]

# 研究与脚本
python scripts/run_baseline_experiment.py --data-file X.parquet [--steps 150] [--seed 42] [--report ...]
python scripts/validate_produced_strategy.py [--data-file data/baseline/BTCUSDT_H1.parquet]
python scripts/proto_batched_vm.py [--T 49500] [--n 192] [--reps 3]
```

## 三、Python 库级接口（import 即用）

| 模块 | 关键入口 |
|---|---|
| `data_pipeline.parquet_manager.ParquetDataManager` | `load(path)` → 提供 `feat_tensor[N,C,T]`、`target_ret[N,T]`、`raw_dict`、`fingerprint`；`data_source_meta()` 产出溯源（symbol/timeframe/文件/日期跨度/指纹）；`inspect_parquet_file(path)` 检查摘要 |
| `model_core.engine.AlphaEngine` | `train(start_step, end_step)`；`_finalize_champion()`（内部冠军闸门，产出 `champion_outcome`）；`_run_finalist_robustness(...)` P3 敏感性；`_build_walk_forward_folds(T, n_folds, gap)` rolling 折叠；`_record_champion_event` 等 |
| `model_core.robustness` | 纯函数：`production_pnl_stats`（生产口径 pnl 统计）、`build_variants`（折叠/起点变体）、`rank_index/annotate_rows/axis_verdict`（三轴判定） |
| `model_core.features.FeatureEngineer` | `compute_features(raw_dict)` → `[N, 65, T]`（registry 驱动，65 特征） |
| `model_core.vm.StackVM` | `execute(formula_tokens, feat)`；`op_map`/`arity_map`/`feat_offset` |
| `model_core.ops.OPERATOR_REGISTRY / OPS_CONFIG` | 62 算子注册表（GT/LT/AND/OR 已移除）；`model_core.vocab.FORMULA_VOCAB`（65 特征 + 62 算子 = 127 token，版本哈希派生） |
| `model_core.backtest.ContinuousBacktest` | `evaluate_fold/evaluate`、`_sortino/_calmar`、`estimate_periods_per_year(times)`（时间戳驱动年化） |
| `model_core.config.ModelConfig` | 训练/闸门/稳健性全部参数（含新 `ENABLE_FINALIST_ROBUSTNESS`、`ROBUSTNESS_TOP_K/COST_MULTS/SHIFT_FRACS`） |
| `web.data_download` | `download_symbol_bars(...)`（同步/后台共用流水线）、`list_download_jobs`、`list_download_history`、`read_parquet_meta` |
| `web.data_sources.binance_source` / `web.tv_history` 等 | 单源抓取（binance `fetch_bars(..., end_time=)` 支持按时间回溯分页） |
| `web.training_manager` / `backtest_manager` / `realtime_manager` | 各自的任务管理单例 |
| `strategy_manager.signal.compute_target_positions_stateless` | 仓位函数（tanh 中性带） |

## 四、数据与产物位置

| 路径 | 内容 |
|---|---|
| `data/training/*.parquet` | 已下载 K 线归档；`{file}.parquet.meta.json` sidecar（source/bars/起止日期/download_count/first_downloaded_at） |
| `strategies/best_{symbol}.json` | 当前冠军策略（vocab_version/symbol/formula/formula_decoded/finalists/holdout/fold_se/seed/data_source 溯源/成本） |
| `strategies/champion_history.json` | 冠军部署/拒绝事件 append-only（拒后含 P3 robustness 复核） |
| `strategies/finalists_{symbol}.json` | 入围 top-K 生产回测指标 |
| `checkpoints/` · `training_history_{symbol}.json` | 检查点与训练曲线 |
| `data/holdout_state.json` | holdout 单次消费状态（数据指纹 → 已批准公式） |
| `logs/` | 服务/训练日志 |

